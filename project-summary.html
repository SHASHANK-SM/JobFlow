JobFlow Dashboard Project Summary

Overview

JobFlow is a job tracking dashboard built to help users organize job applications, monitor interview progress, track follow-ups, and review overall application performance. The project combines a modern front-end dashboard with a lightweight Node.js backend and local MongoDB integration.

What was built

  • Modern job dashboard with premium UI styling
  • Quick-capture form for adding new job applications
  • Job board with status-based cards
  • Apply, interview, offer, and rejected tracking
  • Edit, delete, and advance workflow for each job
  • Search and filtering by company or role
  • Analytics panels for application counts and rates
  • Recent applications, follow-ups, and interview calendar
  • Resume upload support for PDF files
  • MongoDB-ready backend with local fallback storage

Project structure

  • frontend/ – dashboard UI, CSS, and JavaScript logic
  • backend/ – Node.js API server and MongoDB integration
  • frontend/index.html – main dashboard markup
  • frontend/style.css – modern visual styling
  • frontend/app.js – data interactions and render logic
  • backend/server.js – API and MongoDB connection logic

Core features

Application management

Users can add applications with company, role, status, location, salary, source, applied date, and notes. Jobs can then be advanced through pipeline stages, edited, or deleted as needed.

Resume tracking

The quick-capture form includes a PDF-only upload option. Each uploaded PDF is connected to the job record and shown in the dashboard's resume-used section.

Scheduling and follow-ups

The dashboard automatically generates upcoming interview and follow-up items based on each application’s current status, helping users track what to do next.

Analytics

The dashboard includes status summaries, application trends, interview rate, and offer rate so the user can monitor the quality and momentum of their job search.

MongoDB setup

The app connects to MongoDB using a local connection string:

mongodb://localhost:27017/job_tracker

Database used:

job_tracker

Collection used:

jobs

This allows the app to store application data in MongoDB instead of relying only on the JSON fallback.

How to run

  1. Open PowerShell in the project root.
  2. Start MongoDB locally.
  3. Run the backend with the MongoDB environment variables:
Set-Location "C:\Users\Shashank S M\Desktop\Job_tracker_NGS\backend"
$env:MONGODB_URI = "mongodb://localhost:27017/job_tracker"
$env:MONGODB_DB = "job_tracker"
node server.js

Then open:

http://localhost:5000

Important notes

  • Port 5000 must be free before starting the server.
  • MongoDB must be running locally on the machine.
  • Large PDF uploads are kept in the data model as base64 text for local demo purposes.

Final status

The dashboard is now functional as a job-tracking system with strong UI styling, MongoDB support, resume tracking, analytics, and workflow management. It is ready for local use and can be extended into a full production-ready job tracker.
